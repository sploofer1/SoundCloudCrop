# SoundCloud Seamless Banner & Avatar Cropper 🎧

Простой браузерный инструмент для создания идеального визуального оформления профиля в SoundCloud. Позволяет вырезать баннер и аватарку из одного изображения так, чтобы при загрузке они образовали единую бесшовную композицию без смещения пикселей.

## ✨ Основные возможности
* **Точные пропорции SoundCloud:** Автоматическая разметка баннера (`2480×520 px`) и точное позиционирование круга аватара (`400×400 px` с отступами `60 px`).
* **Живой предпросмотр (Live Preview):** Сразу видно, как шапка и аватарка будут выглядеть вместе в десктопном интерфейсе.
* **Трансформация изображения:** 
  * Зеркальное отражение по горизонтали и вертикали.
  * Свободное растягивание и сжатие по осям X/Y.
  * Расширение границ узких картинок с помощью размытого фона (Blur), зеркального повторения краев или заливки цветом.
* **Экспорт в высоком качестве:** Скачивание готового баннера (`2480×520`) и квадратной аватарки (`1000×1000`) одним кликом.
* **Приватность:** Вся обработка происходит локально в браузере на базе HTML5 Canvas без отправки файлов на сервер.
